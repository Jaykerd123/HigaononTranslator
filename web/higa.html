About Higa

Higa helps users translate phrases between Higaonon and English, hear natural speech playback, and save favorite translations for offline use. Built with multilingual TTS and lightweight on-device models.

Key Features
🔊
Natural TTS
High-quality Bisaya/Higa speech synthesis for clear playback.
🔁
Bidirectional Translate
Translate Higaonon ↔ English with contextual support.
📥
Offline Mode
Save favourite phrases and access without internet.
🎓
Learn Mode
Flashcards and pronunciation practice to learn faster.
Built for the Higaonon community — privacy-first, low-bandwidth friendly. Want changes? Open an issue or attach assets in the repo.
